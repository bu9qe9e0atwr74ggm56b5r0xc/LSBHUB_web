# LSB HUB

Веб-приложение для встраивания и извлечения текста в цифровых изображениях 
методом наименее значащего бита (LSB).

## Стек технологий

- **Frontend:** React, TypeScript, Tailwind CSS, Shadcn/ui
- **Backend:** C#, ASP.NET Core Web API
- **База данных:** PostgreSQL
- **Обработка изображений:** ImageSharp
- **Деплой:** Docker

## Структура репозитория

LSB_HUB_WEB/
├── frontend/        # React-приложение
├── backend/         # ASP.NET Core Web API
├── docker-compose.yml
└── README.md
